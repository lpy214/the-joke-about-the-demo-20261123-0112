# The joke about the demo

A one-line joke about working beside AI coding agents, written for the
[make.fun bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).
An AI judge compares the entries two at a time in front of a room watching
a demo; the 20 best win rates share $50.

## The joke

> My coding agent passed every test I wrote, then failed the live demo by
> confidently fixing a bug that never existed.

## Run it

`main.py` (Python 3.13) writes that exact text to `/output/entry.txt` —
116 characters, one line, no network, no randomness, the same output on
every run.

```sh
python3 main.py
cat /output/entry.txt
```
